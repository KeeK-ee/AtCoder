# C++ チートシート: 正規表現 (std::regex)

文字列が特定のパターンに完全に一致するかどうかを検証するための強力なツールです。

---
## 基本的な使い方

### ヘッダと宣言
`<regex>` ヘッダをインクルードし、`std::regex` オブジェクトに検証したいパターンを文字列として渡します。

```cpp
#include <regex>
// パターンを定義
std::regex re("パターン文字列"); 
```

### パターンの一致検証: `regex_match`
* `std::regex_match(対象文字列, パターン)`:
    文字列全体がパターンに**完全に一致**する場合に `true` を返します。一部分だけの一致では `false` になります。

---
## 主要なメタ文字と量指定子

正規表現のパターンは、特殊な意味を持つ「メタ文字」と、その繰り返し回数を指定する「量指定子」を組み合わせて作ります。

### よく使われるメタ文字
* `.` : 任意の一文字（改行を除く）
* `\d`: 任意の数字 (`[0-9]` と同じ)
* `\w`: 任意の英数字とアンダースコア (`[a-zA-Z0-9_]` と同じ)
* `\s`: 空白文字（スペース、タブなど）
* `[abc]`: `a`または`b`または`c`のいずれか1文字
* `[A-Z]`: `A`から`Z`までのいずれかの英大文字1文字

### よく使われる量指定子
直前の文字やグループが何回繰り返すかを指定します。

* `+`: **1回以上**の繰り返し
* `*`: **0回以上**の繰り返し
* `?`: **0回または1回**の繰り返し
* `{n}`: ちょうど **n回**の繰り返し
* `{n,}`: **n回以上**の繰り返し

---
## 実践的なコード例

「英大文字1文字 + 数字1文字以上 + 英大文字1文字」というパターン（例: `A123B`）に一致するかを検証します。

```cpp
#include <iostream>
#include <string>
#include <regex>

int main() {
    // パターン: [英大文字][数字が1回以上][英大文字]
    // C++ではバックスラッシュ'\'をエスケープする必要があるため、
    // '\d' は '\\d' と書くことに注意
    std::regex re("[A-Z][0-9]+[A-Z]");

    std::string s1 = "K2024P";
    std::string s2 = "A1B";
    std::string s3 = "C2D2"; // パターンに一致しない
    std::string s4 = "E5";   // パターンに一致しない

    if (std::regex_match(s1, re)) {
        std::cout << s1 << " matches the pattern." << std::endl;
    }

    if (std::regex_match(s2, re)) {
        std::cout << s2 << " matches the pattern." << std::endl;
    }

    if (!std::regex_match(s3, re)) {
        std::cout << s3 << " does not match the pattern." << std::endl;
    }

    if (!std::regex_match(s4, re)) {
        std::cout << s4 << " does not match the pattern." << std::endl;
    }

    return 0;
}
```

---
## 重要なポイント 📌
* **完全一致**: `regex_match` は文字列全体がパターンに一致するかどうかを見ます。部分的に一致する文字列を探したい場合は `regex_search` を使います。
* **エスケープ**: パターン文字列内で `\` を使いたい場合は、C++の文字列リテラルのルールに従い `\\` と2つ重ねて書く必要があります。
* **パフォーマンス**: 正規表現のコンパイル（`std::regex`オブジェクトの作成）は比較的時間のかかる処理です。ループ内で同じパターンを何度も使う場合は、ループの外で一度だけ`regex`オブジェクトを作成するのが効率的です。
