# C++ チートシート: ビット演算

ビット単位での論理演算や、部分集合の全探索（ビット全探索）など、計算を効率化するためのテクニックをまとめます。

---
## 1. `std::bitset`
固定長のビット列を安全かつ便利に扱うためのクラスです。

### ヘッダと宣言
`<bitset>`ヘッダが必要です。**ビット数はコンパイル時に定数で決まっている必要があります。**

```cpp
#include <bitset>

// 8ビットのビットセットを全て0で初期化
std::bitset<8> bs1; // 00000000

// 文字列リテラルで初期化
std::bitset<8> bs2("10100011");
```

### 主要なメンバ関数
* `bs.set(pos, val)`: `pos`番目のビットを値`val`(0 or 1)に設定します。
* `bs.test(pos)`: `pos`番目のビットが`1`なら`true`、`0`なら`false`を返します。
* `bs.count()`: `1`になっているビットの数を返します。

**【最重要】インデックスの向き**:
`bitset`のインデックス(`pos`)は、**ビット列の右から`0, 1, 2, ...`**と数えます。これは通常の配列のインデックスとは逆なので注意が必要です。
`10100011` の場合:
- `bs.test(0)` は一番右の `1` を調べる
- `bs.test(7)` は一番左の `1` を調べる

## 2. ビット演算子
`int`や`long long`などの整数型に対して直接行うビット単位の演算です。

* **AND (`&`)**: 両方のビットが1なら1。 `1101 & 1011 = 1001`
* **OR (`|`)**: どちらか一方のビットが1なら1。 `1101 | 1011 = 1111`
* **XOR (`^`)**: ビットが異なれば1、同じなら0。 `1101 ^ 1011 = 0110`
* **左シフト (`<<`)**: 全ビットを左にずらす。`x << n` は `x * 2^n` とほぼ同じ。
* **右シフト (`>>`)**: 全ビットを右にずらす。`x >> n` は `x / 2^n` とほぼ同じ。

## 3. ビット全探索
`N`個の要素の「選ぶ/選ばない」の組み合わせ（`2^N`通り）をすべて試すためのテクニックです。ループカウンタの`i`を`N`桁のビット列と見なします。

### ビット全探索の雛形
```cpp
#include <iostream>
#include <vector>
#include <bitset>

int main() {
    int N = 3;
    std::vector<int> items = {10, 20, 30};

    // 0から (2^N - 1) までループ
    for (int i = 0; i < (1 << N); ++i) {
        // ループ変数iをNビットのビット列と見なす
        std::bitset<3> s(i); // 例えば i=5 なら s="101"

        long long current_sum = 0;
        std::cout << "Pattern " << s << ": ";

        // 各ビットをチェック
        for (int j = 0; j < N; ++j) {
            // j番目のビットが1かどうか
            if (s.test(j)) {
                // j番目のアイテムを選ぶ
                std::cout << items[j] << " ";
                current_sum += items[j];
            }
        }
        std::cout << " (Sum: " << current_sum << ")" << std::endl;
    }
    return 0;
}
```
**出力結果**:
```
Pattern 000:  (Sum: 0)
Pattern 001: 10  (Sum: 10)
Pattern 010: 20  (Sum: 20)
Pattern 011: 10 20  (Sum: 30)
Pattern 100: 30  (Sum: 30)
Pattern 101: 10 30  (Sum: 40)
Pattern 110: 20 30  (Sum: 50)
Pattern 111: 10 20 30  (Sum: 60)
```

---
## 重要なポイント 📌
* **`bitset` vs 整数**:
    * `bitset`: ビット数が固定で大きい（64を超える）場合や、ビット操作を安全に行いたい場合に便利。
    * 整数型: ビット数が64以下で、四則演算とビット演算を組み合わせたい場合に便利。
* **ビット全探索の計算量**: `O(N * 2^N)` となります。`N`が20程度までなら実用的です。
