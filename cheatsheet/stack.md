# C++ チートシート: std::stack

「後入れ先出し」（LIFO: Last-In, First-Out）の原則でデータを管理するコンテナアダプタです。積み上げた本のように、一番最後に追加した要素からしか取り出せません。

---
## 基本的な操作

### ヘッダと宣言
```cpp
#include <stack>
stack<要素の型> st;
```

### 主要なメンバ関数

* `st.push(x)`
    スタックの一番上に要素 `x` を積みます（追加します）。

* `st.pop()`
    スタックの一番上の要素を**削除します**。この関数は値を返さないことに注意してください。

* `st.top()`
    スタックの一番上の要素を**参照します**（値を返します）。スタックが空のときに呼び出すと未定義動作となるため、`empty()`で確認してから使います。

* `st.size()`
    スタック内の要素数を返します。

* `st.empty()`
    スタックが空（要素数が0）であれば `true`、そうでなければ `false` を返します。

---
## 実践的なコード例

スタックを使って、文字列を逆順にする簡単な例です。

```cpp
#include <iostream>
#include <string>
#include <stack>

int main() {
    std::stack<char> st;
    std::string s = "AtCoder";

    // 1. 文字列の各文字をスタックに積む
    for (char c : s) {
        st.push(c);
    }
    // スタックの中身 (上から): 'r', 'e', 'd', 'o', 'C', 't', 'A'

    std::cout << "Original: " << s << std::endl;
    std::cout << "Reversed: ";

    // 2. スタックが空になるまで、一番上の要素を取り出して出力する
    while (!st.empty()) {
        // 一番上の要素を取得
        char top_char = st.top();
        std::cout << top_char;

        // 一番上の要素を削除
        st.pop();
    }
    std::cout << std::endl; // -> "redoCtA"

    return 0;
}
```

---
## 重要なポイント 📌
* **LIFO構造**: 「後に入れたものが、先に出る」という単純なルールです。
* **中身は見えない**: `top()`以外でスタックの途中にある要素にアクセスすることはできません。
* **`pop()`は値を返さない**: 一番上の要素を取得したい場合は、`top()`を呼び出してから`pop()`を呼び出す必要があります。
* **用途**: 深さ優先探索（DFS）の実装、括弧の整合性チェック、逆ポーランド記法の計算など、再帰的な処理の代替としてよく使われます。
