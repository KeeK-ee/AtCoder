# C++ チートシート: 累積和 (Prefix Sum)

配列の特定の区間（`l`番目から`r`番目までなど）の合計を、毎回ループを回すことなく高速に(`O(1)`)求めるためのテクニックです。

---
## 1次元の累積和

### 考え方
元の配列を `a` とすると、累積和配列 `s` を以下のように定義します。

* `s[0] = 0`
* `s[i] = a[0] + a[1] + ... + a[i-1]`

これは、`s[i+1] = s[i] + a[i]` という漸化式で簡単に計算できます。

### 区間和の計算
この累積和配列 `s` を使うと、元の配列 `a` の区間 `[l, r]` (l番目からr番目まで、0-indexed) の合計は、以下の式で一瞬で求まります。

**`sum(a[l]...a[r]) = s[r+1] - s[l]`**



### 実装例
```cpp
#include <iostream>
#include <vector>

int main() {
    int N = 5;
    std::vector<long long> a = {10, 20, 30, 40, 50};

    // 累積和配列sを作成（サイズはN+1）
    std::vector<long long> s(N + 1, 0);
    for (int i = 0; i < N; ++i) {
        s[i + 1] = s[i] + a[i];
    }
    // s = {0, 10, 30, 60, 100, 150}

    // 区間[1, 3] (a[1]からa[3]まで) の和を求める
    // つまり {20, 30, 40} の合計
    int l = 1, r = 3;
    long long sum = s[r + 1] - s[l];

    std::cout << "Sum of a[" << l << "..." << r << "] is " << sum << std::endl; // -> 90

    return 0;
}
```

## 2次元の累積和
2次元配列（グリッド）の矩形領域の合計を高速に求める場合にも応用できます。

### 考え方
`s[i][j]` を、左上の`(0, 0)`から`(i-1, j-1)`までの矩形領域の合計と定義します。
`s[i+1][j+1] = s[i][j+1] + s[i+1][j] - s[i][j] + a[i][j]` という漸化式で計算できます。

左上`(x1, y1)`、右下`(x2, y2)`の矩形領域の合計は、以下の式で求まります。
**`sum = s[x2+1][y2+1] - s[x1][y2+1] - s[x2+1][y1] + s[x1][y1]`**

---
## 応用: DPとの組み合わせ（あなたのメモの解説）
あなたのメモのコードは、DPテーブルを更新する際に、直前`K`個の値の合計を累積和を使って高速に計算する、という典型的なテクニックです。

`a[i] = (s[i] - s[i-K] + mod) % mod;`

この `s[i] - s[i-K]` という部分が、「`a[0]`から`a[i-1]`までの和」から「`a[0]`から`a[i-K-1]`までの和」を引いているため、結果的に**「`a[i-K]`から`a[i-1]`までの直前`K`個の和」**を`O(1)`で計算しています。
（`inf`は、おそらくMOD計算のための法 `mod` を意図していると思われます）
