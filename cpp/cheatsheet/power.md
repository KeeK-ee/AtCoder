# C++ チートシート: 累乗計算

`a` の `t` 乗 (`a^t`) を計算する方法をまとめます。`t` が大きい場合は、計算量を削減する工夫が必要です。

---
## 方法1: 単純なループ（tが小さい場合）

指数 `t` が比較的小さい（30程度まで）場合に使える、最もシンプルな方法です。

```cpp
long long int_pow(long long a, long long t) {
    long long res = 1;
    for (int i = 0; i < t; ++i) {
        res *= a;
    }
    return res;
}
```
**注意点**:
* 計算量が `O(t)` なので、`t` が `10^9` のようになると時間切れ（TLE）になります。
* `a` や `t` が大きいと、結果が `long long` の範囲を簡単にオーバーフローします。

---
## 方法2: 繰り返し二乗法（tが大きい場合・競プロ標準）

`t` の2進数表現を利用して、計算量を `O(log t)` に削減するアルゴリズムです。`t` が非常に大きくても高速に計算できます。競技プログラミングでは必須のテクニックです。

### 繰り返し二乗法（MODなし）
```cpp
long long power(long long a, long long t) {
    long long res = 1;
    while (t > 0) {
        // tの最下位ビットが1なら、現在のaを結果に掛ける
        if (t & 1) {
            res *= a;
        }
        // aを二乗していく
        a *= a;
        // tを1ビット右にシフト（tを2で割るのと同じ）
        t >>= 1;
    }
    return res;
}
```

### 繰り返し二乗法（MODあり）
AtCoderなどの問題で「`10^9+7` で割った余りを求めよ」という場合に使うバージョンです。計算の各ステップでMODを取ることで、オーバーフローを防ぎます。

```cpp
long long power_mod(long long a, long long t, long long mod) {
    long long res = 1;
    a %= mod; // 最初にaをmodで割っておく
    while (t > 0) {
        if (t & 1) {
            res = (res * a) % mod;
        }
        a = (a * a) % mod;
        t >>= 1;
    }
    return res;
}

// 使い方
// long long ans = power_mod(2, 100, 1000000007);
```

---
## 方法3: `std::pow` （小数用）

`<cmath>` ヘッダに含まれる標準関数ですが、これは**浮動小数点数（`double`）用**です。

```cpp
#include <cmath>
double result = std::pow(2.0, 10.0); // 2.0の10.0乗
```

**注意！**: `pow(2, 60)` のように整数を渡しても使えますが、内部で`double`に変換されて計算されるため、**大きな整数の計算では誤差が生じて間違った結果になる可能性があります。** 競技プログラミングの正確な整数の累乗計算には、繰り返し二乗法を使いましょう。

---
## 重要なポイント 📌
* **`t`の大きさで使い分ける**: `t` が小さいなら単純ループ、大きいなら**繰り返し二乗法**が必須です。
* **MOD計算**: 余りを求める問題では、必ずMODありの繰り返し二乗法を使います。掛け算のたびにMODを取るのがコツです。
* **オーバーフロー**: MODなしで累乗を計算する場合、結果は爆発的に大きくなります。`long long`でもすぐにオーバーフローするため、扱える範囲は非常に小さいことに注意してください。
